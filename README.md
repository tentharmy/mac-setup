# mac-setup

Reproducible macOS development environment.

## Goals

- Keyboard-first workflow
- Terminal-first configuration
- Minimal visual distractions
- Explicit and reversible configuration changes
- Reproducible setup from a clean macOS installation

## Environment

- macOS 27.2 (26B123)
- Apple Silicon (arm64)
- Administrator account: ilia

## Principles

1. Understand each change before applying it.
2. Prefer configuration as code.
3. Keep defaults unless there is a reason to change them.
4. Document manual setup steps.
5. Verify the setup with a clean rebuild.
